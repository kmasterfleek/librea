# API

Generated by reading the route files: `src/api/routes-*.js`, `src/import/routes.js`, `src/vibe/routes.js`. Everything is JSON in and JSON out unless noted.

**Authentication.** `POST /api/auth/login` sets an `librea_session` cookie (`HttpOnly; SameSite=Strict`, 12-hour TTL) and also returns the token, which may be sent as `Authorization: Bearer <token>` instead. Every request resolves into `ctx.user` and `ctx.scope` before any handler runs (`src/api/context.js`).

**Scope.** Routes do not take a "who am I" parameter. The caller's role determines which records and which fragment visibilities come back; see the scope table in `docs/architecture.md`. Entities are passed through `projectEntity`, which removes names, dates of birth, emails, phones, addresses, external ids and guardians for scopes without PII.

**Errors.** `{ "error": "message" }` with a meaningful status. An unknown route is `404 {"error":"not found"}`. A request body over 64 MB is `413`.

**Auth column below:** `—` public · `user` any signed-in account · `staff` admin or staff · `admin` admin only · `owner` the app's author or an admin.

## Compliance

Registered by `src/compliance/routes.js`, which `src/server.js` imports optionally. Checks are grouped into packs (`core`, `micro`, `alt`) and the active packs come from the edition's `compliance.packs`. Every check reads the SQLite projection: `immunizations`, `documents`, `staff_credentials`, `learning_plans`, `drills`, `enrollment_events`, `contacts` and the rest.

| Method | Path | Auth | Notes |
|---|---|---|---|
| GET | `/api/compliance/status` | staff | Every active check with its summary, no failing lists. Optional `on=YYYY-MM-DD` to ask as of a date. The run is logged to the ledger. |
| GET | `/api/compliance/checks/:id` | staff | One check including what is actually missing, capped at `MAX_FAILING`. |
| GET | `/api/compliance/catalog` | staff | Every check that exists, with `active` marking those this edition's packs run. |
| GET | `/api/compliance/reports` | staff | The CSV reports available, with their parameters. |
| GET | `/api/compliance/reports/:id.csv` | admin | One report as a CSV download. |
| GET | `/api/compliance/mine` | user | A family's or student's own to-do list, scoped to their linked records — "missing: emergency card" without revealing anyone else's. `400` for an account not linked to a student. |
