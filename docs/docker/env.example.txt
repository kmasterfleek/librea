# Librea configuration template.
#
#   cp docs/docker/env.example.txt .env
#
# .env is gitignored — keep it that way, and never put an API key in
# edition.json or in a commit.
#
# (This template lives here rather than at .env.example because this
# workspace's permission settings deny writing any path matching .env.* —
# a secrets guardrail. Copy it into place yourself.)

# ---- server ----------------------------------------------------------------
PORT=4321
# 127.0.0.1 keeps Librea on the loopback interface, which is the right default:
# it speaks plain HTTP, so anything beyond this machine needs a TLS-terminating
# reverse proxy in front. Inside Docker this is overridden to 0.0.0.0 and the
# published port is bound to 127.0.0.1 on the host instead.
HOST=127.0.0.1

# ---- data ------------------------------------------------------------------
# Everything the system knows lives here: ledger.jsonl, vectors.db,
# librea.sqlite, snapshot.json, users.json, invites.json, media/, apps/,
# models/. Back up this folder and you have backed up the school.
LIBREA_DATA=./data

# ---- edition ---------------------------------------------------------------
# district (default) | micro | alt | your own folder under editions/
LIBREA_EDITION=district

# ---- app-builder model provider --------------------------------------------
# template  no model at all, fully offline, deterministic (the default)
# ollama    a model you run; local tags stay on this machine
# anthropic Claude writes the app
#
# Whatever you choose, only your prompt and the data SHAPE are ever sent.
# Student records never reach a provider. Ask the running server:
#   curl -s http://127.0.0.1:4321/api/vibe/provider
LIBREA_MODEL_PROVIDER=template

# Ollama. A model tag ending in :cloud or -cloud runs on Ollama's servers
# through the local daemon — Librea reports that honestly rather than claiming
# to be offline. Swap the tag for a local model and nothing leaves.
LIBREA_OLLAMA_HOST=http://localhost:11434
LIBREA_OLLAMA_MODEL=qwen2.5-coder:7b

# Anthropic model id, used when LIBREA_MODEL_PROVIDER=anthropic.
LIBREA_MODEL=claude-opus-5

# Setting this key selects the anthropic provider automatically when
# LIBREA_MODEL_PROVIDER is unset. Leave it commented out to stay offline.
#ANTHROPIC_API_KEY=sk-ant-...
